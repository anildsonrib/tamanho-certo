# Tamanho Certo: Foto e PDF

App Android que ajusta imagens e PDFs **no próprio aparelho** para que caibam
no tamanho que o usuário precisa enviar.

Sem servidor, sem conta, sem coleta de dados do usuário.

**`applicationId`:** `br.com.tamanhocerto` · `minSdk` 28 · `targetSdk` 36.
